## Ülgen ne yapar

Kodlama araçları zaten iyi çalışıyor, [EVREN](/tr/evren/) de yetenekli açık ağırlıklı modeller
sunuyor. Eksik olan aradaki parça: giriş yapmak, anahtarı güvende tutmak, kullanım koşullarını
kabul etmek, kotayı izlemek, her aracın ayarını doğru yazmak ve Türkçe arayüz. Ülgen bu parçadır.

<CardGrid>
  <Card title="Tek komutla giriş" icon="approve-check">
    E-Devlet adımı atlanamaz; ondan sonrası `ulgen login` komutudur. EVREN'in API anahtarı sayfasını
    açar, anahtarı sorar, koşulları gösterir ve EVREN anahtarı kabul ettikten sonra kaydeder.
  </Card>
  <Card title="Anahtarınız sizde kalır" icon="padlock">

    hiçbir aracın ayar dosyasına, ekrana ya da günlüğe yazılmaz. Claude Code anahtarı hiç almaz.
    Bkz. [Anahtarınız sizde kalır](/tr/using/#anahtarınız-sizde-kalır).
  </Card>

## Kurulum

Linux ve macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/mftnakrsu/ulgen/main/scripts/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/mftnakrsu/ulgen/main/scripts/install.ps1 | iex
```

Pardus, Debian ve Ubuntu paketleri, kaynaktan derleme ve indirilen dosyanın doğrulanması
[kurulum](/tr/install/) sayfasında.

Bir EVREN hesabı (giriş e-Devlet ile yapılır) ve desteklenen araçlardan birinin kurulu olması
gerekir. Sonra şunu çalıştırın:

```sh
ulgen
```

İlk çalıştırmada Ülgen giriş yaptırır, kurulu araçları bulur, hangisini istediğinizi sorar, onu
EVREN için ayarlar ve başlatır. Sonraki çalıştırmalarda aynı aracı doğrudan başlatır. Komutların
ne yaptığı [Ülgen'i kullanma](/tr/using/) sayfasında, her adım bütün seçenekleriyle
[ayrıntılı kılavuzda](/tr/evren-ile-kodlama-araclari/) anlatılır.

## Desteklenen araçlar

| Araç | `ulgen setup <ad>` | Kurulumun yazdığı |
|---|---|---|
| Qwen Code | `qwen` | `settings.json` içine EVREN modelleri |
| opencode | `opencode` | `opencode.json` içine EVREN sağlayıcısı |
| Codex CLI | `codex` | Kendine ait bir profil dosyası, `evren.config.toml`; sizin `config.toml` dosyanıza hiç yazılmaz |
| Claude Code | `claude` | Yalnızca EVREN işçileri için bir beceri dosyası; `ulgen run claude` ayar dosyası gerektirmez |

Claude Code, kendi makinenizde Ülgen'in içindeki bir çeviriciyle konuşur. Anthropic, Claude
Code'un başka modellerle kullanılmasını desteklemez; bu ve diğer
[bilinen sınırlar](/tr/using/#bilinen-sınırlar) Ülgen'i kullanma sayfasında.
